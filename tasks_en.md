# Research Goal and Task List

**Project goal.** Starting from the implemented spatially varying diffusion index in 3D DRAGON2, use Bayesian optimization to explore physically reasonable parameter ranges. Calculate nuclei spectra and relevant secondary-to-primary ratios for candidate parameter sets, compare them with observations, and identify preferred regions. Then iteratively refine the parameter space and numerical settings, verify that numerical errors meet the precision required by the observations, and determine preferred or best-fit propagation parameters with their uncertainties and correlations. This list is a reference for checking research direction; the user specifies the scope of each individual task.

| Order | Task | Completion criterion |
| --- | --- | --- |
| 1 | Define the observational datasets and a consistent objective. Specify data versions, errors, energy ranges, units, solar modulation, and relevant correlations for proton, helium, and secondary-to-primary measurements, including at least a B/C check. Verify the identified CALET year/source mismatch and missing first AMS B/C row. | Any parameter set produces an auditable total objective, contributions from each observable, and residuals. |
| 2 | Connect the existing Bayesian optimization code to the current 3D VariableDelta model so that proposed parameters reach the DRAGON2 configuration and the corresponding simulation result returns to the evaluator. | A small real search completes successive propose–simulate–evaluate cycles. |
| 3 | Define physically justified parameter ranges and joint constraints, distinguishing free parameters, fixed parameters, and zero-gradient controls. Record the reasons for the bounds. | Search points remain valid, and preferred points at a boundary trigger a defined review. |
| 4 | Choose initial numerical settings for the search and establish stable calculations of proton, helium, and relevant secondary-to-primary observables. | Evaluations use consistent settings; failed runs and stale outputs are never treated as valid fits. |
| 5 | Run Bayesian optimization within the defined ranges and assess each candidate against the separate observables. | Obtain a reproducible preferred region, representative DRAGON2 runs, and their objective components rather than surrogate predictions alone. |
| 6 | Test numerical convergence in the preferred region. Hold physical parameters fixed while varying spatial and energy grids, time steps, and other relevant settings; reevaluate or continue the search if necessary. | Numerical errors are small enough not to dominate observational residuals or change the preferred region and fit conclusions. |
| 7 | Determine best-fit parameters, uncertainties, and correlations using numerically adequate calculations, and examine parameter degeneracies. | Report parameter values, intervals, correlations, and sensitivity to numerical settings. Use MCMC only if needed. |
| 8 | Test the plan's physical aim: quantify spectral hardening and the proton–helium spectral-index difference separately, comparing both with observations and a constant-index control. | State what the same model does and does not explain. Support a causal claim about spatial variation with the relevant control; report negative results accurately. |

An independent neural network, long-term maintenance machinery, and a speed competition between optimization algorithms are not preset requirements. This list does not authorize implementation; each change or calculation must stay within the scope specified by the user for that request.
